# ❤️ Adaptive ECG Wearable with Cardiac Resilience Index (DCRI)

An AI-powered Digital Twin framework that continuously learns an individual's normal cardiac behaviour and predicts future cardiac risk using personalized ECG analysis.

---

## Overview

Traditional ECG systems compare patients against population averages.

This project introduces a personalized Digital Twin approach that learns each individual's baseline heart rhythm and calculates a Dynamic Cardiac Resilience Index (DCRI) for early cardiac risk prediction.

The system also forecasts future cardiac resilience and provides explainable AI insights.

---

## Features

- Personalized Digital Twin learning
- Synthetic ECG Simulation
- Dynamic Cardiac Resilience Index (DCRI)
- Explainable AI reasoning
- Real-time monitoring dashboard
- Emergency alert simulation
- 30-day Digital Twin forecasting
